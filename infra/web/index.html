        About the model

        0.774Test AUROC, held-out hospital
        0.243Challenge utility score (0.24–0.28 across runs)
        67%Septic patients warned before onset
        41%Non-septic patients alerted at least once

        An LSTM over six hourly windows of 7 vitals, 6 labs, demographics and "lab was measured" flags, trained on PhysioNet/CinC Challenge 2019 data from one hospital (20,336 patients) and tested once on another (20,000). Training, evaluation and approval run as a SageMaker Pipeline with a Model Registry; the approved model is served from a SageMaker Serverless endpoint.

        Source code and evaluation on GitHub
